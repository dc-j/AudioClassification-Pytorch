# 数智化监控系统需求规格说明书 (部分)

## 1.1. 风机专业

本章节详细描述了针对风力发电机组的数智化监控与运维需求，结合了行业领先的传感器技术、边缘计算、AI大模型及无人化巡检技术，旨在实现从“被动运维”向“预测性运维”的转型。

### 1.1.1. 风电机组全参量状态监测
构建“端-边-云”协同的全感知体系。
- **多维感知融合**：不仅局限于传统的SCADA数据，更深度融合CMS（振动监测系统）高频数据、螺栓松动监测（基于应力片或视觉）、传动链油液在线监测（颗粒计数与理化指标）、塔筒垂直度与振动监测、以及基础沉降的高精度北斗/倾角传感器数据。
- **机器人与巡检协同**：将轨道式巡检机器人（塔筒内/机舱内）与四足机器人（升压站/场站）的巡检视频、红外图像、音频数据实时接入。
- **状态评估与联动**：数智化平台基于多源数据融合算法（如D-S证据理论或卡尔曼滤波）实时评估机组健康度。一旦发现异常（如某处温度突升或异响），系统自动下发指令指挥就近的巡检机器人或无人机前往指定位置进行二次确认，实现“监测-诊断-确认”闭环。

### 1.1.2. 重要部件健康预警
基于机理模型与数据驱动模型的混合驱动，实现核心部件的亚健康管理。
- **监测对象**：重点针对齿轮箱（齿面磨损、断齿）、发电机（轴承故障、绝缘老化）、叶片（结冰、开裂、雷击）、主轴承及变桨系统。
- **深度挖掘算法**：利用长短期记忆网络（LSTM）或Transformer架构对时间序列数据进行趋势预测；结合随机森林等算法进行故障分类。
- **预警机制**：建立部件健康度评分体系（0-100分）。在设备进入故障期前的“亚健康”阶段（如振动趋势轻微抬升但未超限）即发出预警信号，并给出推荐的排查时间窗口（如建议在未来一周的小风天进行），从而降低非计划停机时间，延长MTBF（平均故障间隔时间）。

### 1.1.3. 基于AI大模型的智能预警与高效运行
引入工业级AI大模型，作为系统的“大脑”，处理复杂的多模态数据。
- **多模态故障诊断**：
    - **声纹分析**：利用高灵敏度拾音器采集机舱内及叶片扫风声音，应用音频分类模型（如本项目中的AudioClassification技术）识别异常声响（如轴承啸叫、叶片风哨声），结合振动与油液数据，实现更早期的故障识别（“料敌于先”）。
    - **退化建模**：大模型基于历史全生命周期数据，构建设备性能退化曲线，精确预测剩余寿命（RUL）。
- **功率曲线智能诊断**：
    - 实时对比SCADA实际功率与理论功率曲线，剔除限电、停机等干扰数据。
    - 智能分析功率曲线下偏原因：区分是由叶片脏污/结冰、偏航不对中、还是控制参数不当引起的，并量化发电量损失。
- **智能偏航优化控制**：
    - 利用激光雷达测风或大模型对湍流强度的预测，建立动态偏航策略。
    - 在保证对风精度的前提下，优化偏航动作频率，避免频繁偏航导致的机械磨损和自身能耗增加；在低风速段采用更灵活的死区策略，在高风速段确保精准对风以最大化捕获能量。

### 1.1.4. 基于AI大模型的运维知识库
构建具备语义理解与推理能力的运维专家系统。
- **知识图谱构建**：整合风机厂家维护手册、历史故障工单、专家经验库以及行业标准，构建涵盖“故障现象-故障原因-处理方案-所需备件-工具清单”的知识图谱。
- **智能问答与辅助**：运维人员可通过自然语言（语音或文本）查询故障处理方案。例如提问“23号风机变桨驱动器报过温故障如何处理？”，系统基于RAG（检索增强生成）技术，检索相似历史案例并生成详细的排查步骤和安全注意事项。
- **自学习进化**：系统自动分析每次检修后的反馈报告，修正知识库中的解决方案置信度，不断迭代优化。

### 1.1.5. 风机无人机智能巡检
实现全自动、高精度的叶片及外观巡检。
- **全自主飞行**：数智化系统根据机组报警信息（如叶片气动不平衡）自动生成巡检任务，调度无人机机库。无人机采用RTK高精度定位+激光雷达避障，实现对风机叶片、机舱、塔筒的贴近飞行（距离3-5米）。
- **不停机/微停机巡检**：支持动态视觉捕捉技术，在风机慢速旋转或停机状态下快速完成叶片360度覆盖拍摄。
- **边缘计算与实时处理**：无人机端侧或机库侧部署轻量化AI模型，实时识别叶片裂纹、雷击点、砂眼、油污等缺陷，并进行尺寸量化。
- **缺陷闭环**：巡检结果自动上传云端，生成包含缺陷位置（距离叶根多少米）、等级、修复建议的结构化报告，并直接触发工单系统。
